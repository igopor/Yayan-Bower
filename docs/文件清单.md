## 一、为什么你数出来的数量对不上

同一个目录，三种数法得到三个数，都"没错"，只是口径不同：

| 数法 | 数量 | 说明 |
|---|---|---|
| **git 会传的（本清单）** | **110** | 源码 + 素材 + 脚本 + 文档，合计约 815 KB |
| 目录里实际存在的（不含依赖） | 112 | 多出 `.env` 和 `server/prisma/dev.db` 两个本地文件 |
| 资源管理器"属性 → 包含" | 约 12,900 | 把 `node_modules`（12,747 个）、`web/dist`（22 个）、`.workbuddy`（6 个）全算进去了 |

**四个"找不到"的常见原因**：

1. **目录是分层的，不是平铺的**。`server/` 下只有 3 个条目（`prisma/`、`src/`、`tsconfig.json`），要展开 `src` 才看得到 33 个文件（`routes` 11 个、`services` 11 个、`lib` 7 个、其余 4 个）。清单里写的是相对路径，按斜杠逐级点进去就是。
2. **`node_modules` 会把数量撑爆**。12,747 个依赖文件不是项目代码，`npm install` 会自己装回来，传上去只会让仓库变几十万行。
3. **`.env` 和 `dev.db` 故意不传**。前者是本机密钥配置，后者是本地测试库（里面有测试账号的手机号和积分）。仓库里给的是 `.env.example` 模板 + 四份素材 json，服务器上重建即可。
4. **中文文件名在某些命令下显示成乱码**。`docs/实现说明.md` 在默认 `git status` 里会显示成 `docs/\345\256\236...`，加 `-c core.quotepath=false` 才正常显示。文件本身没问题。
